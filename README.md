# Рыбалка + кража — MVP для Roblox

**Открывай `Place1.rbxl` в Roblox Studio — всё внутри файла:** карта, шаблон базы, скрипты, интерфейс, RemoteEvent'ы.
Rojo не нужен. Папки `src/` и `tools/` — исходники и сборщик, из которых собирается этот файл (для истории изменений и автопроверок).

## Что внутри Place1.rbxl

```
Workspace
  Map                      карта: берег, хаб, мосты, декор (статичные детали)
    Ground / Seabed        суша и дно (заблокированы от случайного выделения)
    Water                  полупрозрачные блоки = где будет вода (при запуске → вода Terrain)
    Hub                    центральный остров: Shop (ShopPromptAttachment), Fountain, HubSpawn
    Bridges, Decor         мосты, пальмы, скалы, маяк, пляж, костёр
    BaseSlots              8 невидимых меток: где встанут базы (атрибут Index)
  Bases                    (появляется в игре) Base_1 … Base_8 — клоны шаблона
ServerStorage
  BaseTemplate             ОДНА база-шаблон: пирс, садок, лампа тревоги, будка + собака, флаг, площадка спауна
ReplicatedStorage
  Shared
    Config                 ← ВСЕ ЧИСЛА БАЛАНСА ЗДЕСЬ (BaseConfig, MapConfig, UIConfig, дальше Fish/Economy/…)
    Util                   Signal, Trove (уборка соединений), Cooldown
    Net, RemoteNames       доступ к RemoteEvent'ам и их список
  Remotes                  RemoteEvent / RemoteFunction
ServerScriptService
  Main                     точка входа сервера: Init/Start всех сервисов по порядку
  Services                 MapService, BaseService (+ следующие этапы)
  Lib/Notify               уведомления игрокам
StarterPlayer.StarterPlayerScripts
  ClientMain               точка входа клиента
  Controllers              NotifyController, HudController (+ следующие этапы)
StarterGui
  HUD                      интерфейс (всё в Scale, адаптирован под телефоны)
```

## План этапов

| Этап | Что | Статус |
|---|---|---|
| 1 | Шаблон базы, 8 клонов с цветами, выдача/освобождение баз, спаун на базе, «Домой» | ✅ готово |
| 2 | Удочка, заброс, поклёвка, мини-игра на тайминг, конфиг рыб, редкости, мутации | ⏳ |
| 3 | Садок (слоты), доход в секунду, рост стоимости, продажа, DataStore | ⏳ |
| 4 | Кража (удержание 3 с), уведомление + мигающая лампа, собака, замок, щит | ⏳ |
| 5 | Магазин и 3 улучшения, доработка интерфейса | ⏳ |

## Как проверить Этап 1

1. Открой `Place1.rbxl` в Studio → **Play** (F5).
   - В Output: `[MapService] вода залита…`, `[BaseService] создано баз: 8`, `[Main] сервер запущен`.
   - Ты появляешься на цветной площадке **своей** базы, лицом к озеру. Вверху — уведомление «Твоя база — …!».
   - Слева вверху плашка с цветом и названием базы. Над флагом базы — твоё имя.
   - Озеро — настоящая вода, в ней можно плавать; выбраться на берег можно прыжком.
2. Дойди по мосту до хаба (магазин, фонтан), нажми **ДОМОЙ** справа — телепорт на базу, кнопка темнеет на 5 секунд (кулдаун проверяет сервер).
3. Меню (Esc) → **Reset Character** → через 3 секунды возрождаешься снова на своей базе.
4. Мультиплеер: вкладка **Test → Clients and Servers → Local Server**, 3 игрока → **Start**.
   - У каждого своя база и свой цвет, на табличках над флагами — имена.
   - Закрой окно одного клиента → его база снова «Свободно».
5. Переполнение: Local Server на **9 игроков** — девятый получает «Все базы заняты», стоит на хабе, кнопки «Домой» нет.
   Закрой любого другого клиента → девятый сразу получает освободившуюся базу и переносится на неё.

Совет: перед публикацией выставь в Game Settings максимум **8 игроков** на сервер (по числу баз).

## Как редактировать

- **Баланс** — только модули в `ReplicatedStorage.Shared.Config`.
- **Шаблон базы** — перетащи `ServerStorage.BaseTemplate` в Workspace, правь, верни обратно.
  Детали, которые красятся в цвет базы, помечены атрибутом `Accent = true`.
  Не переименовывай: `Root`, `SpawnPad`, `FishingSpot`, `Tank/Glass/PromptAttachment`, `Alarm/Lamp`, `Dog`,
  `Flag/Pole/SignAttachment/OwnerSign` (их ищет BaseService; если чего-то нет — в Output будет понятная ошибка).
- **Где стоят базы** — двигай метки `Workspace.Map.BaseSlots` (–Z метки смотрит в сторону озера).
- **Вода** — блоки в `Workspace.Map.Water` можно двигать/растягивать: при запуске в них заливается вода Terrain.

## Для разработки (необязательно)

Файл собирается скриптом на [Lune](https://github.com/lune-org/lune) из `src/` + генераторов в `tools/builder/`:

```bash
lune run tools/build.luau            # tools/base/Place1.base.rbxl + src/ → Place1.rbxl (+ sourcemap.json)
tools/analyze.sh                     # проверка типов по настоящему API Roblox (luau-lsp)
lune run tools/run_tests.luau        # автотесты в симуляторе Roblox (tools/sim)
lune run tools/extract.luau X.rbxl out/   # вытащить скрипты из файла (если правил прямо в Studio)
```
